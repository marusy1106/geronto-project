Как загрузить файл

  1. Нажмите «Загрузить сюда» у нужной папки выше. Откроется GitHub, войдите в аккаунт.
  2. Перетащите файлы в окно или нажмите «choose your files».
  3. Внизу нажмите зелёную кнопку Commit changes.
  4. Через 1–2 минуты обновите эту страницу, и файл появится в списке.
  5. Чтобы создать новую папку: в репозитории нажмите Add file → Create new file и введите имя вида docs/11_Новая_папка/README.md. Первая строка файла станет описанием папки.

Репозиторий публичный, поэтому всё, что в нём лежит, может увидеть любой человек. Не загружайте персональные данные пациентов, документы с подписями и контактами, а также неопубликованные материалы для патентов.
